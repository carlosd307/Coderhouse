# Proyecto SQL - Librería Online

Este repositorio contiene el proyecto de una base de datos para una librería online.

## Ejecución

1. Ejecutar el script para crear la base de datos `libreria_online`.
2. Conectarse a la base de datos creada.
3. Ejecutar el resto del script.

El script crea las tablas `clientes`, `libros` y `compras`, carga datos iniciales, realiza una actualización de precios, elimina un registro de compras y ejecuta consultas para verificar los resultados.
El archivo pre-entrega-modulo4.sql trabaja sobre un segundo dataset de ventas, compuesto por las tablas clientes, ventas, productos y categorias, y contiene consultas de análisis de negocio: rentabilidad por categoría, clientes sin compras y el producto más comprado por cada cliente.

El archivo preentrega_analisis_avanzado.sql trabaja sobre el mismo dataset de ventas y arma un reporte mensual por categoría usando funciones de ventana: ranking de categorías por mes, ventas acumuladas y comparación de cada mes contra el promedio histórico de su categoría.
