# Proyecto SQL - Librería Online

Este repositorio contiene el proyecto de una base de datos para una librería online.

## Ejecución

1. Ejecutar el script para crear la base de datos `libreria_online`.
2. Conectarse a la base de datos creada.
3. Ejecutar el resto del script.

El script crea las tablas `clientes`, `libros` y `compras`, carga datos iniciales, realiza una actualización de precios, elimina un registro de compras y ejecuta consultas para verificar los resultados.
